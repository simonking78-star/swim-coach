# Classic app — retired

This static app was the original Coach Tools. It was kept at `/classic/` as a fallback
after the React app went live, and retired at Phase 6 of the club & squad normalisation
(19 Nov 2026), when the `club`, `squad` and `squad_name` text columns it reads were dropped.

It is no longer built or deployed (`scripts/build-web.sh`), and `/classic/*` redirects to
the React app (`netlify.toml`). The files are kept here for reference only.
